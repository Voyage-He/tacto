Tacto 是一款强调拟真操作的无按钮音乐播放器，基于 Flutter 构建，以黑胶唱片机为灵感。拨动唱片切歌、转动外圈调整进度、移动唱针控制播放，让操作像摆弄一台真实唱片机一样自然；音乐搜索与歌单收藏则融入播放列表的交互中。音乐内容来自 Bilibili，项目包含 Android、iOS 和 Windows 平台工程。

## 一台可以随身带走的唱片机

奶油色背景、黑胶唱片与柔和的封面背景，让播放器像一台小小的桌面唱片机。播放时唱片转动，移动唱针即可开始或暂停；也可以拨动唱片切换歌曲，旋转外圈调整播放进度。

- **寻找音乐**：按歌曲、歌手或视频关键词搜索 Bilibili 内容，点击结果即可播放。
- **整理收藏**：将喜欢的音乐加入收藏或自建歌单，也可以通过收藏夹 ID 导入 Bilibili 公开收藏夹。
- **Bilibili 账号**：在设置中扫码登录，查看自己的公开和私密收藏夹、创建收藏夹并导入歌单；在歌曲的收藏面板中选择云朵图标，可直接收藏到 Bilibili 或取消收藏。
- **翻看播放列表**：查看当前播放队列，选择歌曲，并按歌单顺序聆听。
- **调整氛围**：以歌曲封面作为背景，支持调整背景虚化和渐变强度，设置会保存在本地。
- **保存收藏**：将「我喜欢的音乐」导出为 `listen2.back` 文件，在另一台设备上导入。导入会替换当前收藏，备份不包含音频文件或全部自建歌单。
- **后台聆听**：接入后台音频服务；iOS 支持锁屏与控制中心显示歌曲信息，以及播放、暂停和进度控制。

## 从第一首歌开始

1. 打开搜索，输入歌曲、歌手或视频名称，选择想听的内容。
2. 将歌曲加入「我喜欢的音乐」，或新建歌单整理收藏。
3. 回到唱片机，按住唱头，抬起后拖动，唱针进入唱片范围即可吸附，松手播放；移回支架暂停。也可以轻点唱臂。

唱机下方露出的播放列表可直接点按查看队列，右侧「选歌单」可挑选音乐；中央标签的长按和上滑仍可作为快捷操作。左右拨动标签会预览相邻歌曲的封面与标题，卡片轻轻鼓起后松手切歌，拖回则取消。唱臂拖动未到落针或归位位置时，松手恢复原状态。

播放列表右上方的定位图标可手动回到当前歌曲，并短暂高亮；打开列表或切换当前歌曲时不会自动定位。

首页唱片外左滑进入搜索，右滑进入设置；唱片套上的「收藏」打开歌曲收藏面板。按住外圈时唱片停转，播放中的声音淡出并暂停；进度浮层显示目标时间与调整量。松手定位或取消后恢复之前的播放状态，暂停中调整进度不会自动开始播放。总时长以木刻数字和纹样融入唱机底座；操作时不自动显示教学文字，完整练习教程可从操作说明主动打开。

播放器保留原有唱片尺寸，顶部、播放列表和歌曲信息使用紧凑的单屏布局，主页面无需上下滚动；长标题、大字体和错误重试在各自固定区域内显示。

拟真交互的完整改进意见、首轮范围与后续方向保存在 [播放器 UX 改进记录](docs/player-ux-roadmap.md)。

唱片本身也是操作入口：

| 操作 | 功能 |
| --- | --- |
| 在唱片外圈旋转 | 调整播放进度 |
| 在中央标签上向左 / 向右拨动 | 下一曲 / 上一曲 |
| 在中央标签上向上滑动 | 打开当前播放队列 |
| 在中央标签上向下滑动 | 将当前歌曲收藏到歌单 |
| 长按中央标签 | 打开歌单选择 |

在「新增歌单」中选择「本地创建」可创建空白歌单；选择「平台导入」后粘贴 Bilibili 收藏夹链接或数字 ID，并填写歌单名称。也可点击「从我的收藏夹选择」，扫码登录后选择自己的公开或私密收藏夹。搜索、导入和首次获取音频需要网络，内容能否播放取决于来源是否可用。

设置中的 Bilibili 收藏夹列表用链条图标关联为应用歌单，已关联的收藏夹显示断开链条图标，可取消关联。歌单详情页也提供断开链条图标。默认保留现有歌曲为本地歌单，也可取消勾选后从应用移除歌单；该操作不改动 Bilibili 上的收藏夹或歌曲。一个收藏夹关联多个歌单时，可选择具体歌单取消关联。

Bilibili 登录使用手机客户端扫码并确认。登录凭据保存在系统安全存储中，重启后恢复；失效时需重新扫码，当前尚未实现自动续期。导入的歌单显示 Bilibili 标识，可通过刷新读取平台最新内容。在歌曲收藏面板中选择自己的 Bilibili 收藏夹，添加或取消收藏会同步到平台，并更新本地歌单；需要登录收藏夹所属账号，其他用户的收藏夹仅可查看。本地创建的歌单独立保存。退出登录清除本机凭据，并尝试注销服务端会话。收藏备份不包含登录凭据。

播放列表默认按顺序连续播放：当前歌曲结束后自动播放下一首，切到后台后同样续播，最后一首结束后停止。

设置中的「打开应用时自动播放」默认开启。关闭后，下次启动仍恢复上次的歌曲和队列，但保持暂停；修改开关不影响当前播放，设置会保存到本机。

## 本地运行

项目使用 Flutter **3.24.1**（见 `.fvmrc`），搭配 Riverpod 管理状态、Hive 保存本地数据，并通过仓库内的 `music_api` 包访问音乐内容。

```sh
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```

仓库不提交 `*.g.dart`，首次运行及修改相关模型后需要执行代码生成。iOS 环境准备、真机签名、打包与验收说明见 [开发与构建指南](docs/development.md)。
